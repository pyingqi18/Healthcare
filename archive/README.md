1. 文件夹用途
archive保存2025和2026年的历史代码及notebook，用于追溯项目演变。
2. 使用规则
这里的文件不是现在的正式运行入口。依赖notebook前面单元格留下的状态，变量名和文件路径也会随日期变化。直接从中间运行一个单元格，很容易得到无法复现的结果。正式代码位于src和scripts。
3. 文件修改
历史文件中的明文凭据已经移除，notebook输出和执行计数已经清理。一般不修改历史文件。确认历史问题后，应在正式代码和reports中记录修复，不回写旧版本。


目前的使用规则是：

1\. 查旧方法时阅读archive。

2\. 要重新使用的逻辑先迁移到`src/medical\_ratings/`。

3\. 给迁移后的逻辑增加测试，再从`scripts/`运行。

4\. 发现历史错误时，在正式代码和`reports/整理内容.md`中记录，不回头改旧notebook
