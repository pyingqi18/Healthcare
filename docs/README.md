1. 文件夹用途
   docs保存研究设计、变量定义、阶段分类和流程交接说明。

2. research_design_audit.md
   记录因果解释、样本构造和模型设定中的主要风险。进入回归前必须重新核对。

3. variable_dictionary.md
   记录变量含义、单位、来源和构造方法。面板字段变化后需要同步更新。

4. stage_classification.md
   区分数据收集、预处理、面板、回归和NLP阶段，防止历史notebook被误当作正式入口。

5. handoff_zh.md
   保存当前进度、运行顺序和后续交接信息。

6. search_scope_revision.md
   记录本次多抓原因和全市场重新抓取前需要采用的范围控制方案。
