# 项目整理内容

这份文件不是论文摘要，也不是只给程序员看的更新日志。它按实际发生顺序记录每一步为什么做、用了什么数据、数字怎么变化，以及这些结果能说明什么。

阅读时先记住三件事：

1. 数字尽量单独列出，是为了以后能直接和脚本输出核对。
2. “测试通过”只表示代码按预定规则运行，不表示回归结论正确。
3. legacy、corrected_v1审计和未来final analysis是三个层次，不能把前面的显著结果直接叫最终结论。

如果只想快速了解当前状态，可以从第63节开始读。前62节保留完整过程，是为了以后查清某个数字或模型为什么会变。

3. 初始日期审计
   错误合并后的final_merged_time.csv有5789行，其中4274行具有有效start_date，覆盖率为73.83%。
   合并前诊所表实际为5778行，说明旧时间线合并额外产生11行。重建后重新计算的最终日期覆盖率见第8点。
   这里最重要的不是73.83%，而是旧最终表行数已经被错误合并改变，所以不能继续把5789行当真实诊所总数。

4. ZIP标准化问题
   初次审计发现约38094条评论无法匹配，占4.95%。
   原因是pandas将07087读取为7087.0，旧函数又将其转换为70870，造成虚假未匹配。
   这38094条不是突然丢失的评论，而是前导零处理错误让本来能匹配的ZIP变成了另一个数字。

5. 评论连接审计
   对769515条评论进行互斥分类：
       唯一title + ZIP匹配：757555
       缺少ZIP但名称唯一匹配：11952
       完全无法匹配：0
       歧义匹配：8
   8条歧义评论属于洛杉矶同一地点。旧时间线只按title合并，使该地点同时获得洛杉矶2014年和旧金山2007年两个网站年份。现有证据只能确认两条记录同名但地点不同。
   因此不能为了追求100%自动匹配，强行把同名记录连在一起。

6. clinic_key重复

8. 日期覆盖率
   合并前5778家诊所中：
       有效earliest_review_date：4182
       缺少earliest_review_date：1596
       有效网站年份：409
       同时具有两种日期：342
       仅有网站年份：67

       两种日期均缺失：1529

   也就是说，大多数entry date实际来自最早评论日期，网站年份只额外补了67家。这个变量更接近“最早能观测到的时间”，不应直接写成真实开业日。

10. 审计评论年份和诊所进入年份
    769515条评论日期全部有效，覆盖2008至2026年。
        2008至2014年地区合格评论仅3278条，早期覆盖明显稀疏；2015至2025年共有729462条地区合格评论。2026年只有13505条地区合格评论，属于未完成年度。
    5778家诊所中4249家具有有效entry_date；地区合格诊所中4107家有效，空间合格诊所中4062家有效，1529家缺少进入日期。
    结论：面板累计计算使用2008至2025年的完整评论历史，主要分析期设为2015至2025年。2026年不进入完整年度分析。缺少entry_date的诊所不能作为有明确进入年份的竞争者。
    这一步把“用哪些年份累计”和“回归分析哪些年份”分开了。2008至2014年用于建立历史余额，主要比较从2015年开始。

    1120个候选中只有231个位于目标ZIP，占20.62%；明确牙科187家，占16.70%。769个补查对象中只有15个位于目标ZIP，占1.95%。

50. 固定效应、控制变量和聚类的区别
    Entity Effects吸收每家诊所不随时间变化的特征，包括固定地点、长期品牌和不变的distance_to_hub。
    Year Effects吸收所有市场共同的年度变化，例如Google平台评分环境、评论使用习惯和宏观冲击。
    Market-Year Effects为市场与年份交互组，吸收每个市场每年的共同冲击。模型结构是Entity Effects加Market-Year Effects，不是Entity、Market和Year三个简单相加变量。
    C(mapped_location)、C(State)、C(Category_Location)和C(Keyword_Category)是分类虚拟变量，是否构成固定效应取决于模型结构。
    clustered standard errors只改变不确定性估计，不吸收遗漏变量，不是固定效应。
    density、log_votes_dynamic、clinic_age和distance_to_hub是解释变量或控制变量，也不是固定效应。
    clinic_age等于year减去固定entry_year，在同时具有完整Entity和Year Effects时通常共线。log_votes_dynamic可能受到竞争进入影响，属于潜在post-treatment control，不应在最终主规格中未经比较就默认加入。
    简单区分：fixed effects改变系数依靠什么差异识别，control variable改变条件比较，clustered standard errors只改变误差和显著性计算。

63. 四种strict空间方法的共同结论
        Entity FE下显著的entry-shock定义：gravity、最近entrant距离、三个圆环shock、单独0.5-mile shock
        Entity + Year FE下显著的entry-shock定义：0
        Entity + Market-Year FE下显著的entry-shock定义：0
    各种距离定义给出同一规律：只控制诊所固定效应时，竞争进入与评分存在显著条件关联；加入共同年份或市场年份固定效应后，entry shock普遍缩小且不显著。
    这一稳定模式比某个单独p值更重要。它表明原Entity-only结果主要混入了平台年度变化、评论积累趋势、宏观冲击或市场年度变化。
    局部存量密度存在较一致的负向线索：0.5-mile density为负，圆环最内层density为负，第五active competitor距离为正。三种表达都对应附近竞争越密、评分越低。但这些结果接近5%边界、来自多模型比较，并受到选址内生性影响，目前只能记录为稳健性线索。
    到这里可以停止继续堆模型了。再试更多半径寻找显著p值，只会增加规格搜索，不能增强研究设计。

64. 2-mile与strict空间套件不能直接比较系数大小
    strict 2-mile使用2008至2025年，回归样本24627行和2938家诊所；strict空间套件沿用009a其他方法的2024截止逻辑，使用21689行和2829家诊所。
    strict 2-mile公式为entry shock加log_votes_dynamic，不加入density。gravity、KNN、圆环和0.5-mile模型均同时加入shock、对应density以及log_votes_dynamic。
    因此，2-mile与其他方法之间同时存在样本年份、样本成员和控制变量差异。现阶段可以比较结论方向，不能将系数绝对值排序为哪一种距离方法效果更强。
    最终pipeline必须先固定共同样本，再只替换exposure定义，否则“哪个方法系数大”没有可比意义。

65. log_votes_dynamic的结果和风险
    log_votes_dynamic在12个strict空间模型中始终为正且p值接近0。该变量反映累计评论数量，与评分可见度和平台成熟度高度相关。
        Entity FE系数范围：0.066582至0.098706
        Entity + Year FE系数范围：0.113210至0.115744
        Entity + Market-Year FE系数范围：0.117076至0.119082
    竞争进入可能影响顾客流量、评论数量和评论构成。如果log_votes_dynamic位于竞争影响评分的路径上，将其控制会截断部分真实机制，并可能引入post-treatment bias。
    legacy复现必须保留log_votes_dynamic，因为它属于原公式。最终主规格应默认不控制log_votes_dynamic，并把加入该变量的结果作为敏感性分析。两套结果必须使用同一估计样本进行比较。
    原因是评论数量可能本身受竞争影响。把它放进主模型，可能把竞争通过顾客流量影响评分的路径提前控制掉。
