1. 文件夹用途
   tests验证身份、解析、资格、地点归并、评论抓取、数据替换和面板逻辑。

2. 普通测试
   tests根目录中的测试使用小型人工样本，不连接API，不产生付费任务。

3. 真实数据测试
   tests/integration读取本地data文件，检查真实行数、唯一性、日期、评论连接和面板守恒。使用real_data标记。

4. 常用命令
   运行全部测试使用python -m pytest -q。
   只运行不依赖真实数据的测试使用python -m pytest -m "not real_data" -q。

5. 测试原则
   测试失败时先判断是代码回归、输入版本变化还是历史错误证据发生变化。不得为了通过测试直接删除断言或修改legacy文件。
